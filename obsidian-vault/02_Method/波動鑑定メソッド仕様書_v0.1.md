# 波動鑑定メソッド仕様書 v0.1

> **本ドキュメントは「波動鑑定士」メソッドの唯一の正式仕様(Single Source of Truth)である。**
> 他の設計書(データベース設計書、鑑定ロジック設計書、PDF仕様書等)で計算ルールに矛盾が生じた場合、本書の記述を優先する。
> 仕様変更時は本書を直接改訂し、改訂内容を [[11_Version_History/Wave_Method_バージョン履歴|バージョン履歴]] に記録した上でバージョン番号を上げる(例: v0.1 → v0.2 → v1.0)。

## 0. 本書の読み方

各項目には以下のいずれかのラベルを付す。

- 🟢 **確定仕様**: プロジェクトオーナーが明言し、現時点で変更予定がない
- 🟡 **仮仕様**: 初期案として採用するが、実データ検証を経て変更されることを前提とする
- 🔴 **要検討**: 未決定。実装着手前にプロジェクトオーナーの判断が必要

未確定パラメータ(重み付け・閾値・判定式)は、コードに直接埋め込まず、**設定値として外部化し後から変更可能な構造にする**こと自体が確定仕様である([[04_Wave_Calculation/鑑定ロジック設計書]] 参照)。

## 1. メソッドの基本構造(🟢確定仕様)

```
人生3大波動(固定・第1波/第2波/第3波)
        ×
現在波動(可変・年度ごとに算出)
        ↓
   波の一致判定
        ↓
   5段階の波動レベル
        ↓
「今は動く時か/待つ時か/準備の時か」の提示
```

- 人生3大波動は顧客ごとに一度算出し、翌年以降も原則として再計算・変更しない(「人生波動マスター」)
- 現在波動は年度ごとに新規算出し、過去の年度分を全て保存し続ける
- 表現ポリシー: 未来を断定しない。「タイミングを考えるための視点」として提示する([[01_Concept/波動鑑定士_コンセプト]] 参照)

## 2. 使用する占術と役割マッピング(🟡仮仕様)

| 占術 | 抽出する情報 | 割り当てる波動要素(初期案) | 採用ステータス |
|---|---|---|---|
| 四柱推命 | 大運(長期的な運の流れ) | 人生3大波動の中心データ | 🟡仮仕様 |
| 西洋占星術 | トランジット等 | 現在波動の中心データ | 🟡仮仕様 |
| 数秘術 | 個人年(パーソナルイヤー) | 年間テーマの補助データ | 🟡仮仕様 |
| 九星気学 | (未定) | (未定) | 🔴要検討(有効性検証後に採用可否決定) |
| 紫微斗数 | (未定) | (未定) | 🔴要検討(同上) |
| 宿曜 | (未定) | (未定) | 🔴要検討(同上) |

**重要な表現制約(🟢確定仕様)**: 既存占術そのものに「波形という科学的根拠がある」という表現はしない。複数の占術を独自ルールで統合し、「波」という視覚表現に変換する**オリジナルメソッド**として設計・訴求する。

各占術の計算根拠・出典・ライセンス上の留意点は [[03_Fortune_Methods/使用占術一覧と根拠]] を参照。

## 3. 波動スコア(🔴要検討・変換式は未定義)

占術ごとの生データを共通の数値に変換するための目盛り(仮案)。

| スコア | 意味 |
|---|---|
| +100 | 大きな上昇 |
| +50 | 上昇 |
| 0 | 安定・転換 |
| -50 | 下降 |
| -100 | 大きな下降 |

- 🔴 **要検討**: 上記は目盛りのみであり、「大運のどの状態が+100に該当するか」等、生データ→スコアへの具体的な変換関数(写像規則)が未定義。これは [[04_Wave_Calculation/鑑定ロジック設計書]] で個別に設計する。

### 3.1 重み付け(🟡仮仕様・要検証)

| 占術 | 重み(初期案) |
|---|---|
| 四柱推命 | 50% |
| 西洋占星術 | 30% |
| 数秘術 | 20% |

- この比率は**確定ではない**。実データを用いた検証を経て最終ルールとして確定する。
- 重み付けパラメータは設定値として外部化し、コード変更なしで調整できる設計とする(🟢確定仕様、実装方針)。

## 4. 波の一致判定(🔴要検討・判定式は未定義)

人生3大波と現在波を重ね合わせ、以下のような判定区分を設ける(仮案)。

| パターン | 判定区分(仮称) |
|---|---|
| 人生の波が上昇 + 現在波も上昇 | 上昇シンクロポイント |
| 人生の波が上昇 + 現在波が下降 | 準備・調整ポイント |
| (その他の組み合わせ) | 🔴要検討・未定義 |

- 判定ロジックは後から変更可能な設計とする(🟢確定仕様、実装方針)。
- 🔴 **要検討**: 「上昇」「下降」をどの数値差分・閾値で判定するか、また上記2パターン以外の組み合わせ(両方下降、片方が「安定」等)の判定区分が未定義。

## 5. 5段階の波動レベル(🟡仮仕様)

| レベル | 状態(仮称) | 提示するメッセージ(仮称) |
|---|---|---|
| 1 | 大きな下降 | 整える |
| 2 | 下降・停滞 | 準備する |
| 3 | 転換期 | 見極める |
| 4 | 上昇 | 動き始める |
| 5 | 人生の大波+現在波が大きく一致 | 大きな行動を考える好機 |

- 🔴 **要検討**: 人生3大波(3値)と現在波(1値)、および一致判定の結果から、どの計算式でこの5段階に集約するかが未定義。
- この判定基準も設定値として管理し、後から変更可能にする(🟢確定仕様、実装方針)。

## 6. データ保存の絶対原則(🟢確定仕様)

**人生3大波動と現在波動(年間波動)を、絶対に同じデータとして扱わない。**

- 人生3大波動: 基本固定。顧客あたり1レコード(第1波・第2波・第3波を保持)。
- 現在波動(年間波動): 毎年追加。顧客×年度で1レコード。

```
顧客001
├─ 人生波動(固定): 第1波・第2波・第3波
└─ 年間履歴(追加型): 2026年 / 2027年 / 2028年 ...
```

これにより10年後・20年後でも過去の鑑定履歴を参照できる構造とする。データベース上の実装は [[05_Database/データベース設計書]] を参照。

## 7. リピーター対応の原則(🟢確定仕様)

翌年以降にリピーターが来店した場合:

1. 過去の人生3大波動を再利用する(再計算しない)
2. 現在の年間波動のみを新規算出する
3. 前年との変化を鑑定に含める

🔴 **要検討**: メソッドの計算バージョン(`calculation_version`)自体が改訂された場合、既存顧客の人生3大波動を再計算するか・しないかのポリシーが未定([[00_Project/01_不明点・矛盾点・不足情報一覧]] のD-12参照)。詳細は [[06_Annual_Readings/年間リピート鑑定対応設計]] を参照。

## 8. バージョン管理ルール(🟢確定仕様)

- 本書のバージョンは `v0.1` から開始する
- 仕様変更(スコア変換ルール、重み付け、判定閾値等の確定・修正)のたびにマイナー/メジャーバージョンを上げる
- 変更履歴は [[11_Version_History/Wave_Method_バージョン履歴]] に記録する
- 過去に発行済みの鑑定書がどのバージョンで計算されたかを `life_waves.calculation_version` / `annual_readings` 側にも記録する(データベース設計書参照)
