# テストデータ・サンプル顧客テンプレート

> メソッド検証・実装テスト用の架空データテンプレート。実在人物の実データを使う場合は [[12_Security/セキュリティ・個人情報管理設計書]] の同意取得ルールに従うこと。

## 顧客入力テンプレート([[00_Project/00_プロジェクト概要]] 9章の必須・追加情報に対応)

```yaml
customer:
  name: "(架空)テスト太郎"
  birth_date: "1990-05-15"
  birth_time: "unknown"   # 不明な場合は "unknown" とし、代替算出方針は要検討(SSOT/鑑定ロジック設計書 参照)
  birth_place: "東京都"
  current_occupation: "会社員"
  current_concern: ["仕事", "独立・起業"]   # 複数選択可(仮仕様)

life_events:
  - age: 25
    description: "就職"
  - age: 31
    description: "結婚"
  - age: 38
    description: "独立"

best_period:
  description: "(例)30代前半、結婚〜第一子誕生の頃"

hardest_period:
  description: "(例)20代後半、転職に失敗し半年無職だった時期"
```

## 用途

1. 占術計算エンジンの実装テスト(入力→生データ→波動スコアの動作確認)
2. [[04_Wave_Calculation/鑑定ロジック設計書]] の変換表・重み付け検証(架空データでのロジック疎通確認。実データでの精度検証とは別)
3. PDF鑑定書のレイアウト確認用ダミーデータ

## 要検討事項

- 実顧客データを使ったメソッド検証(重み付け調整等)を行う場合の同意取得プロセス・匿名化方針が未設計(🔴要検討、[[12_Security/セキュリティ・個人情報管理設計書]] と連動)
- サンプルデータのバリエーション(出生時間不明ケース、海外出生地ケース等)の網羅方針は未定
