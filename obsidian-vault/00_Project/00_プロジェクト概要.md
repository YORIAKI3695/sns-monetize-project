# 波動鑑定士 プロジェクト概要(構想分析)

> このファイルは STEP1「構想分析」の成果物。プロジェクト全体の見取り図として使う。
> 詳細仕様は各フォルダの個別設計書、唯一の正式仕様(Single Source of Truth)は [[02_Method/波動鑑定メソッド仕様書_v0.1]] を参照。

## 1. サービスの本質

「波動鑑定士」は占いサービスではなく、**顧客ごとの"人生波動カルテ"を継続的に蓄積するデータベース型サービス**である。

- 一度算出した「人生3大波動」は顧客に紐づく**固定資産データ**として保存される
- 毎年の「現在波動」は**年次で追加され続ける可変データ**である
- 商品(鑑定書)は、このデータ構造の上に成り立つ"表示レイヤー"に過ぎない

この「固定データ + 年次追加データ」という設計思想が、単発の占いコンテンツと本質的に異なる点であり、プロジェクトの中核である。

## 2. 一般的な占いとの違い(要点整理)

| 一般的な占い | 波動鑑定士 |
|---|---|
| 「あなたはこういう性格」「今年の運勢」で完結 | 人生の大きな流れ(3大波)と現在(現在波)を重ね合わせて"タイミング"を可視化 |
| 単発の結果 | 顧客IDに紐づく継続データ、翌年以降も参照・比較可能 |
| 占術単体の結果をそのまま提示 | 複数占術を独自ルールでスコア化・統合した「波」という独自表現に変換 |
| 未来を断定 | 「今は動く時か、待つ時か」という位置づけの提示に留める |

## 3. コンセプトの分解

1. **人生3大波動(固定)**: 第1波・第2波・第3波。顧客ごとに一度算出したら原則変更しない「人生波動マスター」。
2. **現在波動(可変)**: 年度ごとに算出し、`annual_readings` に年次追加。前年との比較も可能にする。
3. **波の一致判定**: 3大波と現在波を重ね合わせ、「上昇シンクロポイント」「準備・調整ポイント」等を判定。
4. **5段階評価**: 判定結果を5レベルに集約し、「今は動く時か/待つ時か/準備の時か」を提示。
5. **鑑定書(PDF)**: 上記をチャートと文章にまとめた商品として出力。

## 4. ビジネスモデルの全体像

```
Instagram → LINE → 無料簡易診断(現在波の簡易版)
  → 本鑑定 5,000円(人生3大波+現在波+PDF)
  → 上位商品 29,800円(仮)(鑑定+パワーストーン)
外部チャネル: ココナラ(鑑定書のみ)/ Etsy(海外向けデジタル鑑定書)
```

最終形は、顧客登録〜決済〜占術計算〜スコア算出〜一致判定〜AI鑑定文生成〜チャート生成〜PDF生成〜LINE納品までの完全自動化。翌年以降はリピーター向けに「3大波は再利用・現在波のみ再算出」というフローを自動化する。

## 5. このプロジェクトの技術的な核心

技術的に最も重要なのは占術の実装そのものより、以下の**データ構造の一貫性**である。

- `life_waves`(固定) と `annual_readings`(年次追加) を**絶対に混同しない**設計
- 波動スコアの重み付け・閾値・判定ロジックを**コードに埋め込まず、後から変更可能な設定値として外部化**する設計
- 10年、20年とデータが蓄積した際にも破綻しないスキーマ設計

## 6. 現状のステータス

このプロジェクトは「叩き台」段階であり、以下は未確定・要検証:

- 占術ごとのスコア変換ルール、重み付け比率
- 波の一致判定・5段階評価の具体的な計算式
- 占術の計算根拠・ライセンス確認
- 価格設定の原価計算
- 個人情報管理の法的整理
