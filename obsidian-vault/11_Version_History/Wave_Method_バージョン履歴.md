# Wave Method バージョン履歴

> [[02_Method/波動鑑定メソッド仕様書_v0.1|波動鑑定メソッド仕様書]](SSOT)の変更履歴。仕様変更時は必ずここに追記すること。

## v0.1 (2026-09-03)

- 初版。プロジェクトオーナーの構想(叩き台)をもとに、STEP1〜STEP10の設計書一式を作成
- 波動スコア・重み付け・一致判定・5段階レベルの具体的な計算式は全て未確定(🔴要検討)のまま初版として発行
- 占術は四柱推命・西洋占星術・数秘術を初期候補とし、九星気学・紫微斗数・宿曜は有効性検証待ちのステータスで登録
- 既存Instagram施策の「6波動タイプ」との関係整理が未了である旨を [[00_Project/01_不明点・矛盾点・不足情報一覧]] に記録

## バージョン更新ルール(🟢確定仕様)

- パラメータ確定・判定式の確定・占術採用可否の決定など、鑑定結果に影響する変更を行った場合はバージョンを上げる
- 軽微な文言修正等、鑑定結果に影響しない変更はバージョンを上げず、本ページに変更日のみ追記する運用も可(🔴要検討: この区分の厳密な線引き)
- バージョン番号は `v0.1` → `v0.2` → … → `v1.0`(実データ検証を経て安定版に到達したタイミングで `v1.0` とする想定、🟡仮仕様)
- 各顧客の `life_waves` / `annual_readings` には算出時の `calculation_version` を必ず記録する([[05_Database/データベース設計書]] 参照)
